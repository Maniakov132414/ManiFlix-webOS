# ManiFlix for LG webOS Smart TV

Ứng dụng Smart TV (`bond.maniakov.maniflix` `v1.0.0`) dành cho LG webOS, cài đặt trực tiếp bằng **webOS Dev Manager** với tệp `.ipk` phát hành tự động trên GitHub Releases.

## Tính năng chính
- Giao diện 10-foot TV tối ưu overscan (`48px` ngang, `32px` dọc) với vòng focus rõ nét và 100% icon vector SVG.
- Điều khiển đầy đủ bằng Remote D-Pad (`37/38/39/40`), `OK`, `LG Back` (`461`), phím Media (`415/19/413/412/417`), phím Màu (`403/404/405/406`), và con trỏ Magic Remote.
- Tìm kiếm bằng bàn phím ảo D-Pad trên màn hình (`A–Z`, `0–9`, Dấu cách, Xoá) và chủ đề nhanh.
- Trình phát HLS (`hls.min.js` tích hợp sẵn + dự phòng native `<video>`), tự động bỏ qua quảng cáo và bỏ qua mở đầu/kết thúc (TheIntroDB) chỉ với 1 lần nhấn `OK`, tua `±15s`, chọn chất lượng/tốc độ/tỉ lệ khung hình, và ngăn chọn tập ngay trong trình phát.
- Kiểm tra mạng TV trực tiếp qua 4 luồng Cloudflare Edge Speedtest + thống kê máy chủ `phim.maniakov.bond`.
